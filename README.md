# YouTube Downloader PRO 🚀

## Features
- Download videos & playlists
- Multiple resolutions (144p → 4K)
- Chrome-style UI
- Progress + speed tracking

## Tech Stack
- Python
- yt-dlp
- CustomTkinter

## Run
pip install -r requirements.txt  
python yt_gui_downloader.py
